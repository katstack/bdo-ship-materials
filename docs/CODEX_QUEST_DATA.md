# BDO Codex 의뢰 카탈로그

앱의 활성 수급 의뢰는 `src/data/quests.ts`에만 둔다. 각 레코드는 문자열 `codexQuestId`, 시작 지역/NPC ID, 목표, 보상과 Codex에서 확인한 충돌 의뢰 ID를 가진다.

Codex origin과 URL 조합은 `src/data/codex.ts`에만 둔다. 데이터 레코드에는 URL을 중복 저장하지 않고, 의뢰는 `group/id/`, 아이템은 숫자 문자열 ID만 저장한다. `items.json`과 `quests.json`은 개발용 로컬 인덱스이며 Git에 포함하지 않는다.

## 확인 방식

1. 개발용 `quests.json`/`items.json`의 정확한 이름 일치 검색으로 Codex ID 후보를 찾는다. `scripts/codex-index.mjs`는 부분 검색을 하지 않는다.
2. `https://bdocodex.com/tip.php?id=quest--{id}&quest_group={group}&l=kr&nf=on` 상세 원문에서 반복 주기, 시작/완료 NPC, 설명, 기본/선택 보상을 확인한다.
3. 이름만 맞고 Codex ID·보상·관계를 확인하지 못한 항목은 활성 수급 카탈로그에 넣지 않는다.

## 현재 검증된 ID

- `3736/12`: 통합된 활기찬 일리야 섬 물물교환 일일 의뢰
- `3727/2`, `3727/3`: 로비니아 보급물자 운송
- `3707/6`, `3707/7`, `3707/8`: 오킬루아의 눈 라비켈 일일 의뢰
- `3707/9`, `3707/10`, `3707/11`: 개별 해왕류 일일 의뢰
- `3707/23`: 그믐달 어린 해왕류 사냥꾼
- `3707/19`~`3707/22`, `3707/25`: 오킬루아의 눈 주간 의뢰
- `3726/1`, `3726/2`: 해란의 레크라샨 사냥터 일일·주간 의뢰

`questRoutes.ts`는 Codex의 원시 충돌 링크를 사용자 선택 UI로 묶는다. 예를 들어 `3707/23`은 `3707/9~11`과 충돌하지만, 개별 3종은 한 수급 루트의 여러 의뢰로 표현한다.
