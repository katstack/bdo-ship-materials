# BDO Codex 의뢰 카탈로그

앱의 활성 수급 의뢰는 `src/data/quests.ts`에만 둔다. 각 레코드는 문자열 `codexQuestId`, 원문 URL, 시작 지역/NPC ID, 목표, 보상과 Codex에서 확인한 충돌 의뢰 ID를 가진다.

## 확인 방식

1. Codex 검색 API `https://bdocodex.com/query.php?a=search&l=kr&sq=...`에서 의뢰 URL과 ID를 확인한다.
2. `https://bdocodex.com/kr/quest/{group}/{id}/` 원문에서 반복 주기, 완료 조건, 기본/선택 보상, `허용되지 않는 퀘스트` 및 `끝나지 않은 퀘스트` 링크를 확인한다.
3. 이름만 맞고 Codex ID·보상·관계를 확인하지 못한 항목은 활성 수급 카탈로그에 넣지 않는다.

## 현재 검증된 ID

- `3727/2`, `3727/3`: 로비니아 보급물자 운송
- `3707/6`, `3707/7`, `3707/8`: 오킬루아의 눈 라비켈 일일 의뢰
- `3707/9`, `3707/10`, `3707/11`: 개별 해왕류 일일 의뢰
- `3707/23`: 그믐달 어린 해왕류 사냥꾼

`questRoutes.ts`는 Codex의 원시 충돌 링크를 사용자 선택 UI로 묶는다. 예를 들어 `3707/23`은 `3707/9~11`과 충돌하지만, 개별 3종은 한 수급 루트의 여러 의뢰로 표현한다.
