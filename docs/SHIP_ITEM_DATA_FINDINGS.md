# 한국어 설명 및 선박 장비 강화 데이터 조사

2026-10-15 두 설치본에서 직접 읽어 검증했다.

## 한국어 설명

한국판 아이템 인라인 문자열은 표시 이름을 제공한다. 아이콘 뒤 추가 문자열, 강화 테이블 기본 단계 설명 및 `stringtable.bss`의 UI 문구를 조사했지만 팔라시 함포(49778), 규격 각목(4685), 통나무(4605)의 일반 설명은 이 경로에 없다. 강화 테이블에서 별도 설명 21개만 나왔다.

NA/EU판의 공통 XML `ui_data/ui_html/xml/<id>.xml`에는 `itemName`, `itemDesc`, 참조 아이템의 `id/name/desc`가 한국어 원문으로 존재한다. 기존 upstream 추출기는 이 이름·설명 필드를 출력하지 않는다. 새 probe는 XML 파서로 본문과 참조 항목을 읽고 아이템 ID에 연결한다. 동일 ID의 본문 설명을 참조 설명보다 우선하며 원본 경로·종류를 보존한다.

3,230개 XML을 읽어 한국어 설명 3,603개를 얻었고 194개 파일은 유효 UTF-8 또는 정상 XML로 파싱할 수 없어 제외했다. 한국판 기본 강화 설명과 합쳐 글로벌 아이템 3,622개에 한국어 설명이 연결됐다. 기존 영문 설명은 `descriptionEn`으로 보존한다.

새 팔라시 함포 ID 49778의 한국어 설명은 이 로컬 조사 경로에서 확보되지 않았다. BDOCodex 일반 페이지는 CAPTCHA를 반환했지만 공개 `tip.php?id=item--<ID>&enchant=0&l=kr&nf=on` 주소는 정상 응답했다. 이 툴팁에서 HTML 구조를 파싱하고 ID를 검증하여 팔라시·치로·토로 장비 36개의 한국어 설명을 추가 확보했다. 설명에 출처 ID와 확인 시각을 남기며, 기존 영문 원문은 보존한다. Codex의 장착 효과는 미해석 식별자 및 클라이언트와 다른 표시가 있어 강화 수치의 출처로 사용하지 않는다.

## 강화 성능

한국판 `itemenchant.dbss`의 인라인 이름 앞 강화 base ID를 `enchantstaticstatus.dbss`에 조인한다. 선박 관련 이름의 아이템 222개에 곡선이 연결됐으며 팔라시 16종, 치로 16종, 토로 4종을 포함한다. 숫자가 있는 장착 효과와 단위를 읽어 웹 상세의 강화별 표에 표시한다. 글로벌 강화 메타데이터는 `globalEnhancement`로 보존한다.

팔라시 점진 함포(49778)의 실제 +0 → +10 값:

- 선박 최대 내구도 증가: 125,000 → 150,000
- 무게 한도 증가: 3,250 → 3,500 LT
- 선박·해양 몬스터 추가 피해: 41,220 → 55,220
- 장비 자체 내구도: 100 → 200

돛의 속도·회전력·제동, 선수상의 속도·가속도·피해 감소율, 장갑의 내구도·무게·식량·피해 감소율도 단계별 수치가 있다. 재장전 속도 효과는 수치가 제공되는 항목에 표시한다.

`CANNON_DAM_CAL`, `CANNON_DAM_CARAVEL`, `CANNON_DAM_FRIGATE`, `DUR_INCRE` 같은 효과는 해당 DSL에 숫자가 없어 별도 미해석 안내에 남긴다. 함포 피해 계산의 최종 수치를 추가 피해와 동일하다고 가정하지 않는다. `enhanceChance` 원시 값은 스택·보정 없는 수치이므로 화면에 최종 강화 성공 확률로 표시하지 않는다.

## 자동화와 검증

`extract-crafting-notes.cmd` 실행 시 한국 강화 상세와 글로벌 공통 한국어 XML 텍스트를 함께 생성·결합한다. 한국어 설명이 없는 항목도 그대로 유지한다. 웹용 청크에는 전체 필드를 보존한다.

클라이언트 추출 후 누락된 팔라시·치로·토로 설명만 Codex 공개 툴팁에서 순차 조회한다. `-SkipCodexDescriptions`로 외부 조회를 생략할 수 있다. 재조회용 스크립트는 `node scripts/fetch-ship-descriptions.mjs <catalog directory>`다. 전체 아이템 웹 크롤링은 하지 않는다.

최종 카탈로그에는 한국어 설명 3,658개가 연결됐다. Windows 자동화의 HTML 파서는 LocalAppData의 `tools/codex-text-fetch`에 준비하므로 WSL pnpm 심볼릭 링크를 Windows Node가 직접 해석할 필요가 없다. Windows Node는 24 LTS를 권장하며 HTML 파서의 지원 최저 버전은 20.18.1이다.

제작 재료 `167821906`은 `(10 << 24) | 49746`이며 기본 아이템은 점진 치로 함포다. 기본 ID가 카탈로그에 존재할 때 `+10` 강화 재료로 표시·연결하며 원본 제작식 참조는 보존한다.

브라우저 회귀 검사에 한국어 규격 각목 설명, 팔라시 함포의 11단계 강화 표와 +0/+10 추가 피해 및 새로고침 복원을 추가했다.
