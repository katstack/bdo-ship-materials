# 제작노트 획득 방법

`src/crafting/acquisition.ts`는 하나의 아이템을 여러 획득 방법으로 연결한다. 제작노트 상세와 원재료 트리에서 `AcquisitionMethods`가 같은 모델을 표시한다. 사용자 재고나 수급 계획은 변경하지 않는다.

| 구분               | 판정 근거                                                 | 가격·수량 처리                                                                                                                              |
| ------------------ | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| NPC 구매           | 아이템 안내 XML의 `vendors.urns` 또는 `unresolvedVendors` | `buyPrice`는 아이템 원본의 기본 가격값일 뿐이다. 실제 상점 가격·통화는 미확인으로 표시한다.                                                 |
| 까마귀 주화 구매   | 기존 `src/data/items.ts`의 한국 공식 업데이트 가격표      | 아이템 ID 우선 연결, 미연결 항목은 공백을 정규화한 이름으로 연결한다. 주화 단가와 기본 가격값을 혼합하지 않는다.                            |
| 물물교환·재료 교환 | `src/data/materialExchanges.ts`에 명시된 항목             | 지급 수량과 변동 비율을 표시한다. 물교 계산기의 미등록 1:1 기본값은 획득 근거로 사용하지 않는다. 요구 교역품·장소는 갱신 목록에서 확인한다. |
| NPC 대여           | NPC 대화에서 추출한 `rentalOffers`                        | `pointType=5`는 공헌도. 다른 유형은 해석하지 않고 원본 유형을 표시한다. 수량·비용·조건을 보존한다.                                          |
| 제작·가공          | 추출된 제작식                                             | 기존 제작식 및 원재료 트리로 확인한다.                                                                                                      |
| 채집               | 아이템 안내의 `gatheredFrom`                              | 확보한 원문 명칭만 표시한다.                                                                                                                |

## NPC 데이터 파이프라인

정규화 스크립트는 해외 클라이언트에서 추출한 `npcs.json`을 카탈로그에 복사한다. 청크 생성 스크립트는 이를 독립적인 해시 기반 `npcs-*.json.zst` 파일로 생성해 manifest의 선택 필드 `npcs`에 연결한다. NPC 정보는 판매처·대여처가 있는 아이템을 열 때만 내려받으며, 기존 압축 해제·해시 검증·Cache API를 재사용한다. 기존 NPC 파일이 없는 manifest도 호환된다.

이름·지역은 현재 해외 클라이언트 명칭임을 화면에 명시한다. 누락된 NPC는 ID 또는 미해석 이름으로 남기며, 로딩 실패는 재시도할 수 있다. NPC별 출현 지역과 상점 접근 조건은 표시하지만 실제 판매 목록 전체, 상점별 가격·특수 화폐·재고를 확보한 것으로 간주하지 않는다. 한국판·해외판 패치 차이 및 오래된 안내문 가능성도 있다.

`buyPrice`만 있는 아이템을 판매 가능한 것으로 추측하거나, 판매가(`sellPrice`)를 구매가로 사용하는 로직을 추가하지 않는다. 추후 실제 상점 오퍼를 추출하면 통화·가격·조건이 있는 별도의 획득 방법으로 연결한다.
